EXPERIMENT 3: DATA CLEANING AND PREPARATION
Problem Statement: Analyzing Customer Churn in a Telecommunications Company

AIM
To explore, clean, standardize and prepare a telecom customer dataset; create useful features; encode categorical variables; scale numerical features; split the data into training and testing sets; and export the results for future customer-churn modelling.

DATASET
- File: Telecom_Customer_Churn.csv
- Original Kaggle filename: WA_Fn-UseC_-Telco-Customer-Churn.csv
- Dataset: Standard Telco Customer Churn dataset.
- Number of customer records: 7,043.
- Target column: Churn (Yes/No).
- Customer identifier: customerID.
- Important numeric columns: tenure, MonthlyCharges, TotalCharges, SeniorCitizen.
- The practical uses Pandas, NumPy, Matplotlib, Seaborn and Scikit-learn.
- The dataset has a special cleaning issue: TotalCharges is stored as text and blank/space-only values must be converted to missing numeric values.
- The notebook keeps valid high values and removes only impossible domain values. It does not blindly delete or cap every IQR-flagged value.
- The train/test split is performed before scaling; StandardScaler is fitted only on training data to avoid data leakage.

4. HANDLE MISSING VALUES AND CORRECT DATA TYPES

for col in df.select_dtypes(include="object").columns:
- select_dtypes(include="object") selects text/object columns.
- .columns gets their names.
- for repeats the indented operation for each column.
- col represents the current column name.

    df[col] = df[col].str.strip()
    - Selects the current text column.
    - .str allows string operations on its values.
    - strip() removes extra spaces from the beginning and end of each text value.
    - The cleaned values are assigned back to the same column.

df["TotalCharges"] = pd.to_numeric(df["TotalCharges"], errors="coerce")
- TotalCharges is originally stored as text, even though it represents a numeric amount.
- pd.to_numeric() converts its values into numeric form.
- errors="coerce" converts values that cannot be interpreted as numbers into NaN (missing values).
- The converted values are assigned back to TotalCharges.

print("Missing values before treatment:")
print(df.isna().sum()[df.isna().sum() > 0])
- isna().sum() counts missing values in every column.
- The second part [ ... > 0] selects only columns whose missing-value count is greater than zero.
- This displays columns that actually have missing values.

zero_tenure = df["tenure"].eq(0)
- Selects the tenure column.
- eq(0) checks which customers have tenure equal to zero.
- It creates a True/False Boolean Series.
- zero_tenure stores that condition.

df.loc[zero_tenure & df["TotalCharges"].isna(), "TotalCharges"] = 0
- .loc selects rows and columns using labels/conditions.
- zero_tenure selects customers whose tenure is zero.
- df["TotalCharges"].isna() selects rows where TotalCharges is missing.
- & means AND: both conditions must be True.
- The second argument "TotalCharges" selects the column to update.
- Those missing TotalCharges values are replaced with 0.
- Reason: a customer with zero months of service has not accumulated monthly charges, so zero is meaningful.

for col in df.select_dtypes(include=np.number).columns:
- Selects all numeric columns using NumPy's number data type category.
- Loops through each numeric column.

    if df[col].isna().any():
    - isna() checks missing values.
    - any() returns True if at least one value is missing.
    - The fill operation runs only if the column contains missing values.

        df[col] = df[col].fillna(df[col].median())
        - median() calculates the middle value of the numeric column.
        - fillna() replaces missing values with that median.
        - The cleaned column is assigned back to df.

for col in df.select_dtypes(include="object").columns:
- Selects the text/object columns and loops through them.

    if df[col].isna().any():
    - Checks whether the current text column contains any missing values.

        df[col] = df[col].fillna(df[col].mode()[0])
        - mode() returns the most frequently occurring value.
        - [0] selects the first mode if multiple modes exist.
        - fillna() replaces missing values with that category.
        - The updated column is assigned back to df.

print("\nMissing values after treatment:", int(df.isna().sum().sum()))
- The first sum() counts missing values per column.
- The second sum() adds those counts to get the overall total.
- int() converts the result to a standard integer.
- Prints the total remaining missing values.

print("TotalCharges type:", df["TotalCharges"].dtype)
- dtype displays the data type of the TotalCharges column.
- It should now be numeric.

Why use different missing-value methods?
- Zero is used for TotalCharges when tenure is zero because it has a specific business meaning.
- Remaining numeric gaps are filled with median.
- Remaining categorical gaps are filled with mode.

IQR CHECK

for col in numeric_cols:
- Repeats the IQR calculation for each selected numeric column.

    q1 = df[col].quantile(0.25)
    - quantile(0.25) calculates the first quartile, or 25th percentile.

    q3 = df[col].quantile(0.75)
    - quantile(0.75) calculates the third quartile, or 75th percentile.

    iqr = q3 - q1
    - IQR stands for Interquartile Range.
    - It measures the spread of the middle 50% of values.

    lower = q1 - 1.5 * iqr
    - Calculates the lower boundary of the IQR outlier rule.

    upper = q3 + 1.5 * iqr
    - Calculates the upper boundary.

    count = int(((df[col] < lower) | (df[col] > upper)).sum())
    - Checks which values are below lower OR above upper.
    - < means less than; > means greater than.
    - | means OR for combining Pandas Boolean conditions.
    - sum() counts how many values satisfy either condition.
    - int() converts the count to an integer.

    print(f"{col}: {count} IQR-flagged values (bounds: {lower:.2f} to {upper:.2f})")
    - Prints the column name, number of flagged values and calculated limits.
    - This line uses an f-string to insert variable values into the text.
    - {lower:.2f} and {upper:.2f} display the limits to two decimal places.

DOMAIN VALIDATION

invalid = (df["tenure"].lt(0) | df["tenure"].gt(72) |
           df["MonthlyCharges"].lt(0) | df["TotalCharges"].lt(0))

Explanation:
- Creates a Boolean condition for impossible values.
- lt(0) means less than zero.
- gt(72) means greater than 72.
- tenure is expected to be between 0 and 72 months.
- MonthlyCharges and TotalCharges should not be negative.
- | combines the conditions using OR.
- invalid is True for any row that violates at least one rule.

print("Impossible domain values:", int(invalid.sum()))
- Counts the rows marked True in invalid.

df = df.loc[~invalid].copy()
- ~ means NOT; it reverses the Boolean condition.
- ~invalid selects rows that are not invalid.
- .loc filters those valid rows.
- copy() creates a separate DataFrame.
- Only impossible records are removed.

print("Rows after domain validation:", len(df))
- Displays the remaining number of rows.

Important concept:
- An IQR-flagged value is not automatically an error.
- A customer may legitimately have high charges or long tenure.
- The notebook reports IQR flags but keeps plausible values.
- It removes only impossible domain values, such as negative charges or tenure outside 0–72 months.

df["TenureGroup"] = pd.cut(

    bins=[-1, 12, 24, 48, 72],

Explanation:
- pd.cut() divides a numeric column into intervals (bins).
- df["tenure"] is the value being divided into groups.
- bins defines the interval boundaries.
- labels provides a readable name for each interval.
- The result is stored in a new column named TenureGroup.
- The groups are: 0–12 months, 1–2 years, 2–4 years and 4–6 years.
- The first boundary is -1 so a tenure value of 0 is included in the first group.

9B. SELECT SERVICE COLUMNS

service_cols = ["PhoneService", "MultipleLines", "OnlineSecurity", "OnlineBackup",

9C. COUNT SERVICES

df["TotalServicesCount"] = df[service_cols].eq("Yes").sum(axis=1)
- df[service_cols] selects all eight service columns.
- eq("Yes") checks each cell to see whether it equals "Yes".
- The result is a True/False table.
- sum(axis=1) adds across each row.
- In Python/Pandas, True is treated as 1 and False as 0 during this sum.
- axis=1 means calculate across columns for each customer.
- The result is the number of selected services for each customer.
- Stores the count in TotalServicesCount.

9D. CALCULATE AVERAGE MONTHLY SPEND

df["AvgMonthlySpend"] = np.where(
    df["tenure"] > 0, df["TotalCharges"] / df["tenure"], 0
)

Explanation:
- np.where(condition, value_if_true, value_if_false) chooses a value based on a condition.
- df["tenure"] > 0 checks whether tenure is greater than zero.
- If True, it calculates TotalCharges divided by tenure.
- If False, it assigns 0 to avoid division by zero.
- The result is stored in AvgMonthlySpend.
- This is the customer's average historical total charge per month of tenure.

- "No" becomes 0.

10. ENCODE AND SCALE FEATURES; SPLIT INTO TRAINING AND TESTING SETS

10A. SEPARATE INPUT FEATURES AND TARGET

X = df.drop(columns=["customerID", "Churn", "Churn_Binary"])
- X represents the input features used by a future machine-learning model.
- drop() removes the listed columns.
- customerID is an identifier, not a useful predictive feature.
- Churn is the original text target.
- Churn_Binary is the numerical target and must not be included in the inputs.
- The remaining columns form X.

- y is the target variable that the model will try to predict.
- It contains 0 for No churn and 1 for Yes churn.

10B. ONE-HOT ENCODE CATEGORICAL FEATURES

X = pd.get_dummies(X, drop_first=True, dtype=int)
- get_dummies() converts categorical columns into numerical indicator columns.
- Each category is represented using 0/1 columns.
- drop_first=True removes the first category from each encoded feature.
- This avoids redundant dummy columns in many modelling situations.
- dtype=int makes the generated values integers.
- The encoded feature table replaces X.

10C. SPLIT INTO TRAINING AND TESTING DATA

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.20, random_state=42, stratify=y
)

Explanation:
- train_test_split() divides input features X and target y into training and testing parts.
- X_train: input features for training.
- X_test: input features for testing.
- y_train: target labels for training.
- y_test: target labels for testing.
- test_size=0.20 reserves 20% of records for testing; the remaining 80% is for training.
- random_state=42 makes the random split reproducible.
- stratify=y keeps approximately the same Yes/No churn proportion in both sets.
- The split is used to evaluate a future model on records it did not train on.

10D. SELECT NUMERIC COLUMNS TO SCALE

scale_cols = ["tenure", "MonthlyCharges", "TotalCharges", "TotalServicesCount", "AvgMonthlySpend"]
- Creates a list of numerical columns that will be standardized.
- These are the continuous/count features selected by the notebook for scaling.

10E. CREATE THE SCALER

scaler = StandardScaler()
- Creates a StandardScaler object.
- StandardScaler transforms values using:
  (value - mean) / standard deviation
- After scaling, each feature in the training data has approximately mean 0 and standard deviation 1.

X_train = X_train.copy()
X_test = X_test.copy()
- Makes separate copies before updating selected columns.
- This avoids modifying an object through a shared reference and helps keep the operations clear.

10F. FIT ON TRAINING DATA AND TRANSFORM BOTH SETS

X_train[scale_cols] = scaler.fit_transform(X_train[scale_cols])
- Selects the scaling columns from training data.
- fit_transform() first learns the mean and standard deviation from the training data, then scales those values.
- The scaled values replace the original values in those columns.

X_test[scale_cols] = scaler.transform(X_test[scale_cols])
- Uses transform() to scale the testing data.
- It uses the mean and standard deviation learned from X_train.
- It does NOT fit a new scaler on the test data.
- This avoids data leakage from the testing set into preprocessing.

Why fit only on training data?
The test set must behave like unseen future data. If its statistics are used during fitting, information from the test set leaks into the training process and evaluation becomes less reliable.

BASIC VIVA QUESTIONS AND ANSWERS
------------------------------------------------------------

1. What is data cleaning?
Finding and correcting missing, duplicate, inconsistent or invalid data so it can be used reliably.

2. What is data preparation?
The process of cleaning and transforming raw data into a form suitable for analysis or machine learning.

3. What is customer churn?
When a customer stops using or leaves a company's service.

4. What is the target variable in this practical?
Churn, converted into Churn_Binary where No = 0 and Yes = 1.

5. What is a DataFrame?
A two-dimensional Pandas structure containing rows and columns.

6. What is Pandas used for?
Loading, cleaning, transforming and analysing tabular data.

7. What is NumPy used for?
Numerical operations and array calculations.

8. What is Matplotlib?
A Python library used to create graphs.

9. What is Seaborn?
A statistical visualization library built on Matplotlib.

10. What is Scikit-learn?
A Python machine-learning library that provides preprocessing, model selection and machine-learning algorithms.

11. What does read_csv() do?
It loads a CSV file into a Pandas DataFrame.

12. What does df.shape return?
A tuple containing the number of rows and columns.

13. What does info() show?
Column names, data types, non-null counts and memory usage.

14. What does describe() show?
Summary statistics such as count, mean, standard deviation, minimum, quartiles and maximum.

15. What is the difference between isna() and isnull()?
In Pandas they are equivalent ways to identify missing values.

16. What is the difference between duplicated() and drop_duplicates()?
duplicated() identifies repeated rows; drop_duplicates() removes them.

17. Why was TotalCharges converted using to_numeric()?
It was stored as text even though it represents a numeric amount.

18. What does errors="coerce" mean?
Values that cannot be converted to numbers are changed into NaN.

19. Why fill TotalCharges with zero for zero-tenure customers?
A customer with zero months of service has not accumulated monthly charges, so zero is meaningful.

20. What is median?
The middle value after arranging values in order.

21. Why use median for numeric missing values?
It is less affected by extreme values than the mean.

22. What is mode?
The most frequently occurring value.

23. Why use mode for categorical missing values?
It fills the missing category with the most common category in that column.

24. What is data standardization?
Making inconsistent text formats or category labels consistent.

25. What does strip() do?
Removes extra spaces from the beginning and end of text.

26. What does title() do?
Capitalizes the first letter of each word and lowercases the remaining letters.

27. What is a duplicate record?
A record that repeats an existing record or identifier.

28. Why is customerID treated specially?
It is a unique identifier and should represent one customer record.

29. What is an outlier?
A value that is unusually far from the general distribution of the data.

30. What is IQR?
Interquartile Range, calculated as Q3 minus Q1.

31. What are Q1 and Q3?
Q1 is the 25th percentile and Q3 is the 75th percentile.

32. What is the IQR outlier rule?
Values below Q1 - 1.5 × IQR or above Q3 + 1.5 × IQR are flagged as potential outliers.

33. Does every IQR outlier need to be removed?
No. It may be a valid observation. Domain knowledge is needed before removing it.

34. What is domain validation?
Checking whether values are possible according to the real-world meaning of the data.

CODE-SPECIFIC WHY / WHAT-IF VIVA QUESTIONS

1. What if the CSV file is not in the notebook folder?
Pandas may raise FileNotFoundError. Place it in the folder or update DATA_PATH.

2. Why use Path() for the file path?
It provides a convenient path object rather than hardcoding the path as a plain string throughout the code.

3. What if TotalCharges is not converted to numeric?
Calculations such as median, division and scaling may fail or behave incorrectly because the values are text.

4. What happens to invalid numeric text when errors="coerce" is used?
It becomes NaN, which can then be handled as a missing value.

5. Why strip all object columns before converting TotalCharges?
Extra spaces around text values are removed, including space-only TotalCharges entries.

6. Why treat zero-tenure TotalCharges separately before median filling?
For those customers, zero is the meaningful value rather than an estimated typical charge.

7. What if a numeric column has no missing values?
The if condition skips the median fill operation.

8. What if a categorical column has no missing values?
The if condition skips mode filling.

9. What if mode() returns more than one value?
mode()[0] selects the first returned mode.

10. What if we use mean instead of median?
The average may be more affected by extreme values.

11. What is the difference between duplicate rows and duplicate IDs?
Duplicate rows repeat all values; duplicate IDs repeat the customer identifier, even if other columns differ.

12. Why drop exact duplicates before duplicate customer IDs?
First remove fully repeated records; then ensure that each customer ID appears only once.

13. What if we use keep="last" instead of keep="first"?
The last record for each repeated customer ID would be retained instead of the first.

14. Why standardize capitalization?
So values such as "yes", "Yes" and " YES " are not treated as separate categories.

15. What if title() is applied to customerID?
It could change the formatting of identifiers, so the notebook excludes customerID from the unique-category display and does not title-case it.

16. Why use astype("int64")?
It converts a column into a 64-bit integer data type.

17. What if a numeric column is left as text?
Mathematical operations and machine-learning preprocessing may not work as intended.

18. What does zip(axes, numeric_cols) do?
It pairs each graph area with one numeric column so the loop can create one boxplot per feature.

19. Why use a boxplot for outlier inspection?
It gives a visual summary of the distribution and highlights potential extreme values.

20. What if a value is outside the IQR limits but is still possible in real life?
It should not automatically be removed. The notebook checks valid business/domain ranges.

21. Why are high MonthlyCharges and TotalCharges retained?
High charges may be legitimate customer values; only impossible negative charges are removed.

22. What if tenure is 80 months?
It is outside the specified 0–72 month range and is flagged as invalid by the domain check.

23. What if MonthlyCharges is negative?
It is considered impossible by the practical's domain rule and the row is removed.

24. What does ~invalid mean?
It reverses the Boolean condition, selecting records that are not invalid.

25. What if we use df.loc[invalid] instead?
That would select the invalid rows rather than retain the valid rows.

26. Why use pd.cut() for TenureGroup?
It converts a numeric tenure value into meaningful customer-duration categories.

27. What if a tenure value is 0?
It falls into the first group because the first bin starts at -1 and ends at 12.

28. What if a tenure value is 72?
It falls into the final group because the final bin ends at 72.

29. What does eq("Yes") do?
It checks which service cells contain exactly the text Yes.

30. Why use sum(axis=1)?
It counts the Yes values across the service columns for each customer.

31. What if axis=0 is used instead?
It would count Yes values down each column across customers, not calculate a service count for each customer.

32. Why use np.where() for AvgMonthlySpend?
It calculates the ratio only when tenure is greater than zero and avoids division by zero.

33. What if tenure is zero and we divide directly?
Division by zero would create an invalid/infinite result or warning. np.where() assigns zero for that condition.

34. Why map No to 0 and Yes to 1?
It creates a binary numerical target suitable for classification.

35. What if Churn contains a category other than Yes or No?
map() would produce a missing value for an unmapped category; the practical assumes the standardized target has only Yes and No.

36. Why remove customerID from X?
An identifier generally does not represent customer behaviour and could mislead a model.

37. Why remove both Churn and Churn_Binary from X?
To avoid target leakage: the answer must not be part of the model inputs.

38. What if drop_first=False is used in get_dummies()?
All category indicator columns are kept. This can create redundant columns for some models.

39. Why split before scaling?
The scaler must learn its statistics from training data only, not from the test set.

40. What if random_state is removed?
The split may be different each time the notebook is run.

41. What if test_size=0.30 is used?
30% of the data is reserved for testing and 70% for training.

42. Why stratify=y?
It helps preserve the proportion of churn and non-churn customers in both splits.

43. What if stratify is not used?
The class proportions in training and testing sets may differ more, especially with imbalanced classes.

44. What is the difference between fit_transform() and transform()?
fit_transform() learns statistics and transforms data; transform() uses already learned statistics to transform new data.

45. Why is fit_transform() used on X_train?
The scaler learns the mean and standard deviation from training features and scales them.

46. Why only transform() on X_test?
It applies the training-set statistics without learning anything from test data.

47. What is data leakage in this practical?
Using test-set information while fitting preprocessing steps, such as fitting StandardScaler on all rows before splitting.

48. What should the mean of scaled training columns be?
Approximately zero.

49. Does StandardScaler make every value fall between 0 and 1?
No. It standardizes around mean zero and standard deviation one; values can be below zero or above one.

50. Why is y_train saved separately from X_train?
X_train contains predictors; y_train contains the correct target labels for those training records.

51. Why use to_frame() for y_train?
A Pandas Series is one-dimensional; to_frame() converts it into a DataFrame with a named column before saving.

52. Does this notebook predict which customers will churn?
No. It prepares the dataset for a later model; model training and prediction are not included.
