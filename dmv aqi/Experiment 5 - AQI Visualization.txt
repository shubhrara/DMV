EXPERIMENT 5: DATA VISUALIZATION USING MATPLOTLIB
Problem Statement: Analyzing Air Quality Index (AQI) Trends in Pune

AIM
To explore historical daily air-quality data for Pune and visualize AQI and pollutant trends, monthly comparisons, distributions, and relationships between AQI and pollutants.

SOURCE AND DATASET NOTES
- Dataset file: City_Air_Quality.csv (included in the ZIP folder).
- The notebook uses US AQI and six pollutant measurements.
- Pollutants: PM2.5, PM10, Carbon Monoxide, Nitrogen Dioxide, Sulphur Dioxide and Ozone.
- The dataset does NOT contain a Dominant_Pollutant category. Therefore, the notebook does not create one. Its AQI box plot compares months instead.
- Missing measurement values are filled using time-based interpolation in both directions. Filled values, especially at the beginning or end, are estimates, not newly observed readings.
- Required libraries: pandas, numpy, matplotlib.

4. TASK 3: PREPARE THE RELEVANT VARIABLES

df["date"] = pd.to_datetime(df["date"])
- Selects the date column and converts its values into Pandas datetime format.
- Datetime format allows date-based calculations and time-based interpolation.
- The converted values are stored back in the date column.

df = df.sort_values("date").reset_index(drop=True)
- sort_values("date") sorts rows in ascending date order.
- reset_index(drop=True) creates a fresh 0, 1, 2... row index.
- drop=True prevents the old index from being added as a separate column.
- Chronological order is important for time-series analysis.

aqi_col = "us_aqi"
- Stores the column name "us_aqi" in a variable.
- This makes it easier to refer to the AQI column in later code.

pollutant_cols = [
    "pm2_5", "pm10", "carbon_monoxide",
    "nitrogen_dioxide", "sulphur_dioxide", "ozone"
]
- Creates a Python list containing the six pollutant column names.
- A list lets the code select or process multiple columns together.

measurement_cols = pollutant_cols + [aqi_col]
- [aqi_col] creates a one-item list containing the AQI column name.
- + joins the two lists.
- measurement_cols now contains all six pollutant columns plus the AQI column.

df = df.set_index("date")
- Makes date the DataFrame index.
- A time-based index is needed for interpolation with method="time".

df[measurement_cols] = df[measurement_cols].interpolate(
    method="time", limit_direction="both"
)
- Selects the AQI and pollutant measurement columns.
- interpolate() estimates missing values using surrounding available values.
- method="time" uses the time interval between observations when estimating values.
- limit_direction="both" allows filling in both directions, including missing values at the start and end.
- This is an estimate; it does not create actual sensor observations.

df = df.reset_index()
- Converts the date index back into an ordinary date column.
- The date can now be accessed as df["date"].

df["month"] = df["date"].dt.to_period("M").astype(str)
- .dt accesses datetime properties of the date column.
- to_period("M") converts each date to a monthly period, such as 2024-01.
- astype(str) converts the monthly period into text.
- Stores the result in a new column named month.

df["month_name"] = df["date"].dt.strftime("%b %Y")
- strftime() formats a date as text.
- %b means abbreviated month name; %Y means four-digit year.
- Example: Jan 2024.
- Stores a readable month label for graph axes.

print("Prepared variables:")
print(["date", aqi_col] + pollutant_cols)
- Prints the names of the variables selected for analysis.
- The list combines date, AQI and pollutant columns.

print("\nMissing values after interpolation:")
print(df[measurement_cols].isnull().sum())
- Checks how many missing values remain in the selected measurement columns after interpolation.

assert df[measurement_cols].isnull().sum().sum() == 0, "Some measurement values are still missing."
- assert checks whether a condition is True.
- The first sum() counts missing values per column; the second sum() adds those counts.
- == 0 checks that the total number of missing measurement values is zero.
- If the condition is False, Python raises an AssertionError with the given message.
- If it is True, execution continues.

print("\nAll selected AQI and pollutant measurement columns are complete.")
- Displays a confirmation after the assertion succeeds.

5. TASK 4 & 9: LINE PLOT OF OVERALL AQI TREND

df["aqi_7_day_average"] = df[aqi_col].rolling(window=7, min_periods=1).mean()
- Creates a new column for the 7-observation moving average of AQI.
- rolling(window=7) considers a moving window of seven rows.
- min_periods=1 allows an average even when fewer than seven observations are available at the beginning.
- mean() calculates the average within each window.
- This smooths short-term changes and makes the general trend easier to see.

plt.figure(figsize=(13, 5))
- Creates a graph 13 inches wide and 5 inches high.

plt.plot(df["date"], df[aqi_col], label="Daily US AQI", alpha=0.55)
- Draws a line graph of daily AQI against date.
- label gives the line a name for the legend.
- alpha controls transparency; 0.55 makes the line partly transparent.

plt.plot(df["date"], df["aqi_7_day_average"], label="7-day moving average", linewidth=2.5)
- Adds the moving-average line to the same graph.
- linewidth=2.5 makes this line thicker.

plt.title("Daily AQI Trend in Pune")
plt.xlabel("Date")
plt.ylabel("US AQI")
- Adds the title and labels for the x-axis and y-axis.

plt.legend()
- Displays the line labels.

plt.grid(True, alpha=0.3)
- Turns on grid lines.
- alpha=0.3 makes the grid light/transparent.

plt.gca().xaxis.set_major_formatter(mdates.DateFormatter("%b %Y"))
- gca() gets the current graph axes.
- xaxis accesses the horizontal axis.
- set_major_formatter() controls how the main date ticks are displayed.
- DateFormatter("%b %Y") displays dates like Jan 2024.

plt.xticks(rotation=30)
- Rotates date labels by 30 degrees so they are easier to read.

plt.tight_layout()
- Adjusts spacing so labels and titles do not overlap or get cut off.

plt.show()
- Displays the graph.

Interpretation:
- The daily line shows individual AQI changes.
- The 7-observation average smooths short-term fluctuations.
- A moving average shows a trend; it does not prove the cause of AQI changes.

pollutant_labels = {
    "pm2_5": "PM2.5",
    "pm10": "PM10",
    "carbon_monoxide": "Carbon Monoxide",
    "nitrogen_dioxide": "Nitrogen Dioxide",
    "sulphur_dioxide": "Sulphur Dioxide",

- Creates a dictionary.
- A dictionary stores key-value pairs.

fig, axes = plt.subplots(3, 2, figsize=(14, 11), sharex=True)

- fig stores the complete figure.
- axes stores the individual graph areas.
- figsize sets the full figure size.
- sharex=True makes all six graphs share the same x-axis scale/date range.

axes = axes.flatten()

for i, col in enumerate(pollutant_cols):

    axes[i].plot(df["date"], df[col], linewidth=1.4, label=pollutant_labels[col])

    axes[i].set_title(pollutant_labels[col] + " Trend")

7. TASK 6 & 9: MONTHLY BAR PLOT AND STACKED BAR PLOT

monthly = df.groupby("month", sort=True).agg(
    month_name=("month_name", "first"),
    average_aqi=(aqi_col, "mean"),
    average_pm25=("pm2_5", "mean"),
    average_pm10=("pm10", "mean"),
    average_no2=("nitrogen_dioxide", "mean")
).reset_index()

Explanation:
- groupby("month", sort=True) groups records by month and sorts the month groups.
- agg() performs multiple aggregation calculations for each group.
- month_name=("month_name", "first") takes the first readable month label in each group.
- average_aqi=(aqi_col, "mean") calculates the monthly average AQI.
- average_pm25 calculates the monthly average PM2.5.
- average_pm10 calculates the monthly average PM10.
- average_no2 calculates the monthly average nitrogen dioxide.
- reset_index() turns the grouped month index back into a normal column.
- monthly stores the resulting summary table.

plt.title("Monthly Average US AQI in Pune")

7B. STACKED BAR CHART OF MONTHLY POLLUTANT AVERAGES

plt.figure(figsize=(11, 5))
- Creates a new graph.

plt.bar(monthly["month_name"], monthly["average_pm25"], label="PM2.5")

plt.bar(monthly["month_name"], monthly["average_pm10"],

plt.bar(monthly["month_name"], monthly["average_no2"],

- Draws nitrogen dioxide above the first two segments.

- This creates a stacked bar chart.

plt.title("Monthly Average Pollutant Levels (Stacked)")

plt.ylabel("Measured level")
plt.xticks(rotation=35)
plt.legend()
plt.grid(axis="y", alpha=0.3)

Important interpretation:
- The stacked chart visually places the three monthly average measurements on top of each other.

8. TASK 7 & 9: BOXPLOT AND VIOLIN PLOT

8A. BOXPLOT OF AQI VALUES FOR EACH MONTH

month_groups = [
    df.loc[df["month"] == month, aqi_col].dropna().values
    for month in sorted(df["month"].unique())
]
- This is a list comprehension: a compact way to create a list using a loop.
- df["month"].unique() gets the distinct month values.
- sorted() arranges those month values in order.
- For each month, df["month"] == month creates a True/False condition.
- df.loc[condition, aqi_col] selects AQI values for that month.
- dropna() removes missing AQI values.
- values extracts the underlying array of values.
- month_groups becomes a list where each item contains the AQI observations for one month.

month_labels = [
    pd.Period(month).strftime("%b %Y")
    for month in sorted(df["month"].unique())
]
- Creates a readable label for each month.
- pd.Period(month) converts the month text into a monthly period.
- strftime("%b %Y") formats it like Jan 2024.
- The labels correspond to the month groups.

plt.figure(figsize=(13, 5))
- Creates a graph.

plt.boxplot(month_groups, tick_labels=month_labels)
- boxplot() draws one box for each month's AQI values.
- tick_labels supplies the month names shown along the x-axis.
- A box plot summarizes median, quartiles, spread and potential outliers.

plt.title("Distribution of AQI Values Across Months")
plt.xlabel("Month")
plt.ylabel("US AQI")
plt.xticks(rotation=35)
plt.grid(axis="y", alpha=0.3)
plt.tight_layout()
plt.show()
- Adds labels, rotates month names, adds grid lines, adjusts spacing and displays the chart.

How to read a box plot:
- Middle line inside the box: median.
- Bottom and top of box: first and third quartiles.
- Box height: interquartile range (IQR).
- Whiskers show the range under the plotting rule.
- Points beyond whiskers, if shown, are potential outliers.

Why monthly groups?
- The supplied dataset does not contain a Dominant_Pollutant category.
- The notebook therefore compares AQI distributions across months instead of inventing pollutant categories.

violin_data = [df[col].dropna().values for col in pollutant_cols]

9. TASK 8 & 9: SCATTER PLOT AND BUBBLE CHART

9A. SCATTER PLOT: PM2.5 AGAINST AQI

plt.figure(figsize=(7, 5))
- Creates a graph 7 inches wide and 5 inches high.

scatter = plt.scatter(
    df["pm2_5"], df[aqi_col],
    c=df[aqi_col], cmap="plasma", alpha=0.75, label="Daily observations"
)
- scatter() creates a scatter plot where each dot is one daily observation.
- X-axis is PM2.5; Y-axis is US AQI.
- c=df[aqi_col] colours points according to their AQI values.
- cmap="plasma" selects the plasma colour map.
- alpha=0.75 controls point transparency.
- label gives the plotted points a legend label.
- The returned scatter object is stored in scatter for the colour bar.

x_values = df["pm2_5"].to_numpy()
y_values = df[aqi_col].to_numpy()
- Selects PM2.5 and AQI columns.
- to_numpy() converts their values into NumPy arrays.
- These arrays are used for numerical calculations.

slope, intercept = np.polyfit(x_values, y_values, 1)
- polyfit() fits a polynomial to the data.
- 1 means a first-degree polynomial: a straight line.
- It returns two values: slope and intercept.
- The fitted line has the form y = slope*x + intercept.

trend_x = np.linspace(x_values.min(), x_values.max(), 100)
- linspace() creates 100 evenly spaced x-values.
- The values run from the minimum PM2.5 value to the maximum PM2.5 value.
- These points are used to draw a smooth straight trendline.

plt.plot(trend_x, slope * trend_x + intercept,
         color="black", linewidth=2, label="Linear trendline")
- Calculates the predicted y-coordinate of the straight line for every trend_x value.
- Plots the line in black with width 2.
- label identifies it in the legend.

plt.colorbar(scatter, label="US AQI")
- Adds a colour bar explaining how point colours correspond to AQI values.
- scatter is the object returned by plt.scatter().

plt.title("Relationship Between PM2.5 and US AQI")
plt.xlabel("PM2.5")
plt.ylabel("US AQI")
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
- Adds title, axis labels, legend and grid, adjusts spacing and displays the graph.

Interpretation:
- The scatter plot helps inspect whether higher PM2.5 values tend to occur with higher AQI values.
- The trendline shows the overall linear direction.
- This visual relationship alone does not prove causation.

9B. BUBBLE CHART: PM10 AGAINST AQI

plt.figure(figsize=(8, 5))
- Creates a graph.

bubble_sizes = df["carbon_monoxide"].clip(lower=0) / df["carbon_monoxide"].max() * 250 + 10
- clip(lower=0) replaces values below zero with zero.
- Dividing by the maximum scales the values relative to the largest carbon monoxide measurement.
- Multiplying by 250 controls the bubble-size scale.
- Adding 10 ensures the bubbles have a minimum visible size.
- The result is stored in bubble_sizes.
- Bubble size represents carbon monoxide measurement.

bubble = plt.scatter(
    df["pm10"], df[aqi_col],
    s=bubble_sizes,

    alpha=0.65, edgecolors="black", linewidth=0.3

- X-axis: PM10.
- Y-axis: US AQI.
- s=bubble_sizes sets the size of each bubble using carbon monoxide.
- c=df["pm2_5"] colours bubbles according to PM2.5.
- cmap="viridis" selects the viridis colour map.
- alpha=0.65 sets transparency.
- edgecolors="black" gives bubbles black outlines.
- linewidth=0.3 sets outline thickness.
- The scatter object is stored in bubble for the colour bar.

plt.colorbar(bubble, label="PM2.5 level")
- Displays the colour scale for PM2.5 values.

plt.title("PM10 vs US AQI (Bubble Size = Carbon Monoxide)")
plt.xlabel("PM10")
plt.ylabel("US AQI")
plt.grid(True, alpha=0.3)
plt.tight_layout()

- Adds title, axis labels and grid, adjusts spacing and displays the chart.

How to read the bubble chart:
- Horizontal position represents PM10.
- Vertical position represents US AQI.
- Bubble size represents carbon monoxide.
- Bubble colour represents PM2.5.
- It shows four pieces of information in one graph.
